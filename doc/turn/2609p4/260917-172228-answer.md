## 六、已确认与流水线优化事项

1. **解决 GitHub Pages API 404/403 权限限制**：
   - GitHub 官方的 `actions/configure-pages` 会调用 Pages REST API，在仓库未将 Source 设为 `GitHub Actions` 时会报错 `404 Not Found`，若强行开启 `enablement: true` 又会因 Token 权限限制报 `403 Resource not accessible by integration`；
   - **优化方案**：在 [`.github/workflows/pages.yml`](file:///home/ms/document/code/jotcash/.github/workflows/pages.yml) 中改用成熟的 `peaceiris/actions-gh-pages@v4`，直接将 `./static` 目录发布到仓库的 `gh-pages` 分支；
   - **收益**：Action 运行过程完全不调用 Pages REST API，仅需标准 `contents: write` 权限，流水线 100% 稳定运行通过，避免了 API 鉴权报错。GitHub 识别到 `gh-pages` 分支后会自动完成静态网页服务。
